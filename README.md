# Онлайн-запись для груминг-студий (PWA)

Ядро по промпту «24 часа вайбкодинга» (SGX), адаптированное под груминг: мультитенантная онлайн-запись, которая переодевается под новую студию через один `business.json`.

- Клиент: главная с фото и прайсом → запись в 4 шага в нижней шторке (услуга → размер питомца → мастер → время → контакты) → подтверждение, .ics, «Мои записи», перенос/отмена по ссылке.
- Владелец (`/s/{slug}/owner`): записи по дням и мастерам, статусы, оплата, перенос, запись по звонку, закрытие времени и выходные, цены, статистика.
- Демо: `tenants/pompon` (груминг, Екатеринбург), `tenants/murr` (второй тенант для проверки изоляции).

Документы: [SETUP.md](SETUP.md) · [CLONE-IN-6-MINUTES.md](CLONE-IN-6-MINUTES.md) · [ACCEPTANCE.md](ACCEPTANCE.md)

```
src/                  фронтенд (без названий студий)
supabase/migrations/  схема, RPC, RLS, публикация
supabase/setup.sql    всё в одном файле для SQL Editor
tenants/<slug>/       business.json (+ media/) — вход конвейера
scripts/              tenant:new|validate|publish|verify|owner|static, setup:sql
tests/db, tests/e2e   SQL-интеграционные и Playwright-тесты
```
