# Приёмка — что реально проверено

Дата: 10.10.2026. Окружение проверки: Postgres 16 + PostgREST 12.2.3 + Supabase Auth (GoTrue v2.170) локально, база поднята **тем же** `supabase/setup.sql`, который запускается в SQL Editor. Боевой проект Supabase из среды разработки недоступен (сетевые ограничения) — на нём проверки не выполнялись.

## Не проверено / осталось

- Боевой проект Supabase: `setup.sql` не запускался на нём из среды разработки. После запуска: `npm run tenant:verify -- pompon --site <url>`.
- Деплой на Vercel и установка PWA на реальные iPhone/Android (standalone, иконки, стартовые экраны) — нужен живой URL и устройства.
- Фото Unsplash и Google Fonts в тестах были подменены (внешняя сеть недоступна). Вид с настоящими фото — смотреть на развернутом сайте.
- Неудачные попытки записи (ошибка внутри транзакции) не увеличивают счётчик лимита — откатываются вместе с запросом.

## Не входит в ядро (этап 2, сознательно не реализовано)

- AI-чат записи (`LLM_BASE_URL/LLM_API_KEY/LLM_MODEL`, серверные инструменты, tool loop, JSON-intent fallback, бюджет LLM).
- Web Push через VAPID, outbox `notification_jobs`, Supabase Cron. Сейчас владелец видит новые записи в кабинете (обновление каждые 30 с), клиент — добавляет визит в календарь файлом .ics.
- Edge Functions (в ядре вся логика — SQL-функции с `security definer`, отдельный backend не нужен).
- Загрузка фото владельцем в Supabase Storage.
- `--live` активация без ручного шага проверки.
